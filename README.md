# Floripa AR - Website Profissional

Site profissional para a empresa Floripa AR, especializada em climatização e ar condicionado em Florianópolis.

## 🚀 Estrutura do Projeto

```
site_floripa_ar/
├── index.html          # Página principal
├── css/
│   └── style.css      # Estilos CSS
├── js/
│   └── script.js      # JavaScript para interatividade
├── assets/            # Pasta para imagens
│   ├── logo.png       # Logo da empresa (ADICIONAR)
│   ├── hero-image.jpg # Imagem principal (ADICIONAR)
│   └── about-image.jpg # Imagem sobre nós (ADICIONAR)
└── README.md          # Este arquivo
```

## 📋 Funcionalidades

- ✅ Design responsivo (mobile, tablet, desktop)
- ✅ Menu de navegação com scroll suave
- ✅ Seção Hero com call-to-action
- ✅ História da empresa
- ✅ Serviços oferecidos
- ✅ Avaliações de clientes
- ✅ Formulário de contato integrado com WhatsApp
- ✅ Mapa do Google Maps
- ✅ Botão flutuante do WhatsApp
- ✅ Links para redes sociais (Instagram, Facebook, YouTube, WhatsApp)

- ✅ Formatação automática de telefone

## 📸 Imagens Necessárias

Adicione as seguintes imagens na pasta `assets/`:

1. **logo.png** - Logo da empresa (recomendado: 200x60px, fundo transparente)
2. **hero-image.jpg** - Imagem principal do site (recomendado: 800x600px)
3. **about-image.jpg** - Imagem da equipe/empresa (recomendado: 600x600px)

## ⚙️ Configurações Importantes

### 1. Número do WhatsApp

Substitua `5548999999999` pelo número real nos seguintes locais:

- `index.html` - Linha 52 (botão hero)
- `index.html` - Linha 276 (botão flutuante)
- `index.html` - Linha 339 (footer)
- `js/script.js` - Linha 61 (formulário)

**Formato**: `55` + `DDD` + `número` (exemplo: `5548991234567`)

### 2. Links das Redes Sociais

Edite os links no `index.html` (linhas 316-331):

```html
<a href="https://instagram.com/SEU_USUARIO" ...>
<a href="https://facebook.com/SUA_PAGINA" ...>
<a href="https://youtube.com/SEU_CANAL" ...>
```

### 3. Endereço no Google Maps

Atualize o iframe do mapa (linha 252-260) com o endereço real da empresa:

1. Acesse [Google Maps](https://www.google.com/maps)
2. Busque o endereço da empresa
3. Clique em "Compartilhar" → "Incorporar um mapa"
4. Copie o código e substitua o `src` do iframe

### 4. Informações de Contato

Atualize no `index.html`:

- **Telefone**: Linha 222 e 338
- **Email**: Linha 228 e 339
- **Endereço**: Linha 234
- **Horário**: Linha 240-241

### 5. História da Empresa

Edite o texto da seção "Sobre Nós" (linhas 86-98) com a história real da empresa.

### 6. Avaliações de Clientes

Substitua as avaliações de exemplo (linhas 168-220) por avaliações reais dos seus clientes.

## 🌐 Como Usar

1. **Desenvolvimento Local**:
   - Abra o arquivo `index.html` diretamente no navegador
   - Ou use um servidor local (Live Server, Python, etc.)

2. **Publicação**:
   - Hospede em qualquer servidor web
   - Opções gratuitas: GitHub Pages, Netlify, Vercel
   - Opções pagas: Hostinger, HostGator, etc.
